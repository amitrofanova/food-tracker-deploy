# Food Tracker

[🇬🇧 English](README.md) | 🇷🇺 Русский

Веб-приложение для отслеживания ежедневного питания, ведения пищевого дневника и контроля калорий.

## Функции

- Регистрация и аутентификация пользователей (JWT)
- Пищевой дневник — запись приёмов пищи по типу (завтрак, обед, ужин, перекус)
- Суточная сводка по калориям и макронутриентам (белки, жиры, углеводы)
- Расчёт нормы калорий
- Поиск продуктов по API
- Создание кастомных продуктов
- Конструктор рецептов с расчётом питательности на порцию
- Работа офлайн: локальные данные хранятся в IndexedDB (Dexie) с опциональной синхронизацией с сервером

## Стек технологий

### Клиент

| Технология                                | Роль                              |
| ----------------------------------------- | --------------------------------- |
| Vue 3 (Composition API, `<script setup>`) | UI-фреймворк                      |
| TypeScript                                | Типизация                         |
| Pinia                                     | Управление состоянием             |
| Vue Router                                | Клиентская маршрутизация          |
| TanStack Query                            | Серверное состояние и кэширование |
| Dexie (IndexedDB)                         | Локальное хранилище               |
| Vite                                      | Сборщик                           |
| Capacitor                                 | Обёртка для Android/iOS           |
| FSD (Feature-Sliced Design)               | Архитектура                       |

### Сервер

| Технология   | Роль               |
| ------------ | ------------------ |
| Fastify      | HTTP-сервер        |
| Prisma       | ORM                |
| PostgreSQL   | База данных        |
| JWT + bcrypt | Аутентификация     |
| Zod          | Валидация запросов |

## Структура проекта

```
food-tracker-deploy/
├── client/                  # Vue 3 SPA
│   └── src/
│       ├── app/             # Инициализация приложения, роутер, глобальные стили
│       ├── pages/           # Компоненты страниц (уровень маршрутов)
│       ├── widgets/         # Составные UI-блоки (шапка, блок приёма пищи и т.д.)
│       ├── features/        # Пользовательские действия (поиск продуктов, создание и т.д.)
│       ├── entities/        # Модели и UI (user, product, diary-entry, recipe)
│       └── shared/          # Переиспользуемый UI, API-клиент, конфиг, стили
├── server/                  # Fastify API
│   ├── src/
│   │   ├── controllers/     # Обработчики маршрутов
│   │   ├── routes/          # Определения маршрутов
│   │   ├── middleware/      # Middleware аутентификации
│   │   └── lib/             # Экземпляр Prisma-клиента
│   └── prisma/
│       ├── schema.prisma    # Модели данных
│       └── migrations/      # История миграций
├── Dockerfile               # Продакшн multi-stage сборка (клиент + сервер)
├── docker-compose.yml       # Локальная разработка (горячая перезагрузка)
└── docker-compose.prod.yml  # Локальное тестирование продакшн-сборки
```
